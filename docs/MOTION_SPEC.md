# B 方案：浅色精密工作台 · 交互分镜

用户已选择 B 方向。本文件限定正式工作台的交互动效；计算数据只读取真实后端事件，不生成虚构进度或布局。用户确认记录由主代理保存。

## 构图与操作路径

固定左侧模式轨约 6%，工作区约 94%；工作区顶部是名称、来源和动作。二维主视区约 76%，右侧结果仪表约 24%；参数台位于主视区下方，按「场景与材料 → 算法与方向 → 搜索与运行」组织。高级参数收起但可见入口。运行时页面自动进入二维 / 三维相应工作区，真实预览和过程面板保持在可视范围。正文不低于 14 px，标签与辅助文字不低于 12 px。

## 实现约束

- 支持 `prefers-reduced-motion: reduce`；所有页面、提示和图形过渡均关闭，不影响读数和操作。
- 主画布高度稳定，轮询事件不得引起页面抖动或把用户从回看位置拉回实时。
- 二维缩放 / 平移和三维相机操作由用户直接控制，不安排自动运镜。
- 过程轨迹只显示真实时间和指标；没有新方案时显示阶段 / 心跳文字，不使用假百分比。
- 事件回看受限于本次页面实际获取的快照；缺失阶段不补帧。历史任务没有过程快照时明确说明。
- 停止、失败和未排满订单是不同状态；临时几何快照与最终独立校验结论分开标注。

## B 方向第二轮：操作与视觉层级

- 画布上方始终显示实际输入摘要：材料规格、允许方向、求解工具和时限。点击摘要展开对应设置并聚焦表单；材料规格在展开设置内常显。完整设置默认收起，运行提交后自动收起。
- 主操作为「实验设置 / 自定义画图 / 运行排料」。新建与裁片清单进入「更多操作」；点击外侧、选择动作或按 Escape 收起菜单。
- 专注画布通过工具条进入、退出；Escape 也可退出。专注模式只调整界面构图，不改变图形坐标。Ctrl / Cmd + Enter 运行当前二维或三维配置；对话框和多行文本编辑中不触发。
- 当前目标决定主读数：定宽为使用长度，整板为原料数，选件为总价值。已排需求作为质量读数，利用率为辅助读数。输入预览不显示上次任务的指标。
- 首次真实布局到达前，画布、图例与状态统一显示等待，禁用空白 SVG 导出。阶段只使用任务返回的准备 / 搜索 / 停止状态。
- 选中使用实际几何轮廓、约 2 px 非缩放描边和轻微阴影；不缩放真实形状。重绘时按任务、材料、裁片类型及同类型次序恢复选择；原始输入支持双击编辑。编辑已有类型明确「保存修改」，新建明确「加入裁片」。
- 场景异步读取按请求版本处理，旧响应不得覆盖新选择。场景切换后保留最近一份可撤回的输入草稿，不恢复或伪造历史结果。
- 视觉分工：暖朱红表示主要动作，蓝色表示选择与控件，青绿表示真实完整方案，琥珀表示部分方案与提示。真实过程曲线保持原数据，只有颜色与层级调整。
