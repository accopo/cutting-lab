## 配色职责

| 用途 | 颜色 | 行为含义 |
|---|---|---|
| 工作区底色 | `#f5f5f2` / 白色 | 保持长时间阅读与观察轮廓的舒适度 |
| 导航与主读数 | `#182638` / `#223a55` | 确定页面结构与结果焦点 |
| 主运行动作 | `#c64b30` | 本次计算的主要入口 |
| 编辑、选择与过程 | `#315cda` | 可操作对象、当前视图与真实运行状态 |
| 验证通过 | `#087b69` | 明确校验状态；始终同时使用文字 |
| 预算或待重算 | `#926219` | 提示需注意的输入或结果状态 |

裁片使用有区分度的分类色，选中只改变描边和阴影；不改变实际点坐标、旋转、尺寸，也不在求解等待期间制造假布局。

## 操作路径

1. 选择行业与样件，首屏确认材料、方向、算法和时限摘要。
2. 点击摘要或“实验设置”展开配置；材料与常用方向可直接修改。
3. 点击主运行按钮或使用快捷键。收起配置，进入实时预览，真实候选到达后更新画布和读数。
4. 点击裁片看参数并进入相应类型编辑；结果仍保留与其输入的版本关系。
5. 可进入专注画布，或回看真实快照；停止任务保留已收到方案。
6. 行业报告提供工艺、算法、软件、示例和官方来源，详细内容按需展开。

## 验收重点

桌面和窄屏层级、主按钮与设置入口、参数摘要真实性、实时自动切换、取消保留、快照回看、选中与编辑、二维绘图、三维建模、报告展开、键盘与减少动态效果。实际回执记录在 UI_ACCEPTANCE.md。
